# Light Food

Este proyecto es una aplicación de **Light Food**, construida con [Next.js](https://nextjs.org/).

## Empezando

Para ejecutar el servidor de desarrollo:

```bash
npm run dev
# o
yarn dev
# o
pnpm dev
# o
bun dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.
